A football analytics project focused on exploring player role classification through clustering techniques and statistical profiling.

The project uses football event and performance data to group players based on stylistic and statistical similarities, with the goal of identifying tactical player archetypes and role patterns.

## Features

- Exploratory player clustering
- Statistical player profiling
- Data preprocessing and feature selection
- Dimensionality reduction experiments
- Tactical role comparison
- Football event data analysis

## Technologies Used

- Python
- pandas
- NumPy
- scikit-learn
- matplotlib
- Jupyter Notebook

## Methods Explored

- K-Means clustering
- Feature scaling and normalisation
- Dimensionality reduction
- Statistical comparison between player groups

## Data Sources

- FBref data (when it was still available
- StatsBomb event data

## Goal

The goal of the project is to explore how machine learning techniques can be applied to football data in order to identify player roles, tactical similarities, and stylistic profiles.
